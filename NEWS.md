# DSLD release notes

## 2.0.0

- Removed the dependency on the archived `fairness` package.
- Corrected prediction, standard-error, frequency-table, and plotting errors.
- Fixed positive-class scoring and made cross-validation comparisons consistent.
- Improved Python interoperability, examples, and installation guidance.
- Preserved existing R function signatures and bundled datasets. Corrected
  calculations may change numerical results; invalid inputs now give clearer errors.
- Updated the maintainer email to mittalaa@uci.edu.
